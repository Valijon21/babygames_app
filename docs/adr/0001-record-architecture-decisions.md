# 1. Record Architecture Decisions (ADR)

Date: 2026-10-15  
Status: Accepted  

## Context
We need to record architectural decisions made on this project so that all contributors and autonomous coding agents understand the context, constraints, and consequences of key technical choices.

## Decision
We will use Architecture Decision Records (ADRs) as documented by Michael Nygard. Each ADR will describe a context, the decision taken, its status, and the consequences.

## Consequences
- Every significant technical choice will have an immutable, version-controlled rationale.
- Future refactorings or expansions will be grounded in documented trade-offs.
